# VideoLink

Site completo (frontend + backend) para receber links de YouTube/TikTok e gerar MP4 usando yt-dlp.

## Requisitos
- Node.js 20+
- Internet no servidor
- FFmpeg instalado e disponível no PATH (necessário para alguns vídeos/formatos)

## Rodar
```bash
npm install
npm start
```
Abra http://localhost:3000

## Observação
Use o serviço somente para conteúdo que você tem autorização para baixar/converter e respeite os termos das plataformas e direitos autorais.
